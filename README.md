# 物业智能管家2.0

> 基于大语言模型的物业智能问答Agent系统

## 项目背景
传统物业客服依赖人工接线，响应慢、效率低、无法7x24在线。本项目基于LLM + Agent架构，实现物业场景的智能问答、工具调用和数据持久化，让AI管家能自主判断业主意图并调用对应工具完成任务。

## 技术栈
- **Web框架**：FastAPI + Uvicorn
- **LLM**：通义千问（qwen-turbo）via LangChain OpenAI兼容接口
- **Agent框架**：LangChain（bind_tools手动拼装ReAct链路）
- **数据库**：SQLite
- **对话记忆**：自定义ChatMemory（限制最大轮数防token溢出）

## 核心功能

### 6大工具能力
| 工具 | 功能 | 示例 |
|------|------|------|
| 物业费查询 | 根据房号查欠缴金额 | "3-201欠多少物业费？" |
| 报修登记 | 为业主创建报修工单 | "我要报修，房号3-201，水管漏水" |
| 报修进度查询 | 根据工单号查处理状态 | "工单R10001到哪了？" |
| 投诉/建议登记 | 受理业主投诉并生成编号 | "我要投诉楼道灯坏了" |
| 停车费查询 | 查车位信息和缴费状态 | "3-201停车费交了吗？" |
| 公告查询 | 按类别查小区通知 | "最近有停水通知吗？" |

### Agent核心能力
- **自主决策**：模型根据业主问题自行判断调用哪个工具
- **多轮对话**：记住上下文，支持连续对话
- **数据持久化**：报修、投诉记录存入SQLite，重启不丢失
- **人设约束**：System Prompt限定管家角色和回复规范
